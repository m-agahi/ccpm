# Security Policy

## Supported Versions

| Plugin      | Version | Supported |
| ----------- | ------- | --------- |
| code-review | 3.x     | Yes       |
| update-jira | 1.x     | Yes       |

## Reporting a Vulnerability

If you discover a security vulnerability, please report it privately by contacting
[@maxagahi on Codeberg](https://codeberg.org/maxagahi).

Please include:

- Description of the vulnerability
- Steps to reproduce
- Affected plugin and version
- Potential impact

I will acknowledge reports within 48 hours and aim to release a fix within 7 days for critical issues.

**Please do not open a public issue for security vulnerabilities.**
